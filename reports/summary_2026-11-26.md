# 정리 (2026-11-26): 기본 Tar-7B 는 그림 내용을 쓰지 못한다

r06 (RLVR, 그림 뒤 bridge 강제) 에서 그림 사용은 늘었지만 정답률은 오르지 않았다 (`r06_status_2026-11-25.md`).
그 원인을 가르기 위해 학습 없이 세 가지를 확인했다.

1. 지금 그리는 그림에 문제 정보가 있나 → **없다** (Stage 0)
2. 정답 그림을 넣어 주면 도움이 되나 → **안 된다**: math·maze·clutrr 모두 정답 그림 = 다른 문제 그림 (Stage 1, 1b)
3. r06 은 bridge 없이도 그림 뒤에 이어 쓰나 → **아니다**: 그림을 닫으면 바로 EOS (probe)

결론: 병목은 "좋은 그림 그리기" 가 아니라 **"그림 토큰 읽기"** 다. 다음 결정은 reading-SFT vs backbone 교체.

## 5. 판단

- 세 태스크, 두 스케일 (S2, S0) 에서 정답 그림의 내용이 출력에 영향을 주지 않는다. 그림은 내용과 무관하게 행동만 바꾼다.
- 따라서 RL 로 "그림 그리기" 를 강화해도 정답률이 오를 경로가 없다 (r06 결과와 일치).
- **다음 결정: reading-SFT vs backbone 교체.** 어느 쪽이든 "주어진 그림에서 정보를 읽어 답에 쓰기" 가 지금 0 이라는 출발점은 같다.
- reading-SFT 전에 확인할 것: **S0 토큰에 라벨 (이름·숫자) 이 남는가** (TA-Tok round-trip). 남지 않으면 SFT 로도 읽을 정보가 없어 backbone 교체가 맞다.
